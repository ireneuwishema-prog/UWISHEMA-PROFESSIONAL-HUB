# UWISHEMA PROFESSIONAL HUB

Welcome to the **Uwishema Professional Hub**, a modern, multi-pathway web application built to connect technical talent and educators with meaningful career opportunities. 

## 🚀 Vision: Where Talent Meets Opportunity

Uwishema Professional Hub bridges the gap between hiring institutions and professionals. The platform offers purpose-built pathways to showcase skills, build structural portfolios, and prepare for career acceleration.

---

## 🛠️ Main Pathways

The platform serves two primary user categories:

### 1. 💻 Software Developers
* **Tech Stack Showcase:** Present code languages, framework proficiencies, and developer specialties.
* **Portfolio Integration:** Seamlessly link active application builds, repositories, and live project demos.
* **Visibility:** Make engineering experience discoverable for technology recruiters.

### 2. 🍎 Private School Teachers
* **Academic Profiling:** Highlight subject focus, qualifications, and curriculum specialties.
* **Methodology Spotlight:** Show off unique classroom structures and modern pedagogical techniques.
* **School Connectivity:** Link teacher availability directly to institutional school networks.

---

## 🎨 Architecture & Technical Overview

The user interface features a fully responsive design complete with accessibility fallbacks (`skip-links` and semantic ARIA targets), smooth micro-interactions, dark-mode branding accents (`#071b35`), and modular authentication structures.

### Tech Stack
* **Frontend:** Clean Semantic HTML5, CSS3 Custom Properties (Variables), Vanilla JavaScript (ES6+).
* **Typography:** Integrates `DM Sans` and `Manrope` web engines via Google Fonts.
